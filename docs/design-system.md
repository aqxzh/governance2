# Стандарт оформления

## Выбранная основа

**shadcn-svelte Vega + Zinc + Blue**, светлая тема по умолчанию.

Это готовые цветовые шкалы Tailwind, а не вручную подобранные HEX-цвета. Zinc задаёт нейтральную основу shadcn; Blue — близкий к исходному фирменному синему акцент. Вместо исходного `#2242D6` используется **blue-700** (`#1447E6`). IBM Plex и композиция сайта сохранены.

Источники: [палитры Tailwind](https://tailwindcss.com/docs/colors), [темизация shadcn-svelte](https://www.shadcn-svelte.com/docs/theming). Установленный стиль и базовая палитра записаны в `components.json`; семантические переменные — в `src/routes/layout.css`.

## Цветовые роли

| Семантический токен                     | Готовая шкала    | Применение                                    |
| --------------------------------------- | ---------------- | --------------------------------------------- |
| background / card / popover             | white            | Основная поверхность, карточки, модалки       |
| foreground                              | zinc-950         | Основной текст                                |
| primary / ring                          | blue-700         | Главные действия, ссылки, номера, фокус       |
| primary-foreground                      | white            | Текст главной кнопки                          |
| secondary / muted / accent              | zinc-100         | Вторичные поверхности и hover                 |
| muted-foreground                        | zinc-600         | Вторичный текст, в том числе на muted-панелях |
| border / input                          | zinc-200         | Общие границы и поля                          |
| destructive                             | red-600          | Ошибки и опасные действия                     |
| hero-surface / footer-surface           | zinc-950         | Тёмные брендовые секции                       |
| hero-foreground / hero-muted-foreground | white / zinc-200 | Текст поверх тёмного hero                     |

Для мелкого вторичного текста выбран Zinc 600, а не более светлый Zinc 500: сохраняется контраст AA на серых панелях. `.dark` использует те же готовые шкалы (акцент blue-400 с тёмным текстом); переключатель темы не добавлялся. Этот контекст предназначен для последующих тёмных демо, не для отдельной новой палитры.

## Компоненты

- Button: штатные `default`, `outline`, `secondary`, `ghost`, `link`. Главное действие — default, вторичное — outline. Не переопределять вручную их цвет, border, font-weight, radius или shadow.
- Card, Dialog, Sheet: штатные поверхности, границы, тени и типографика shadcn. Не добавлять локальные «почти такие же» серые и синие.
- Радиусы — стандартная система shadcn от `--radius: 0.5rem`: sm 4px, md 6px, lg 8px, xl 12px. Кнопки используют md, карточки/модалки/крупные изображения — xl.
- Отступы — шкала Tailwind; композиционные изменения допустимы, косметические переопределения примитивов — нет.
- Для переносов длинных переводов допустимы `h-auto`, `min-h-11`, `whitespace-normal`. Это не отдельный стиль кнопки.
- Размеры заголовков, ширина контейнера и моноширинные подписи относятся к композиции сайта, а не к палитре.

## Продолжение разработки

Новые секции используют `bg-background`, `bg-card`, `text-foreground`, `text-muted-foreground`, `border-border`, `bg-primary`, а не `bg-blue-*`, `text-zinc-*` или HEX в компонентах. Новое назначение цвета сначала оформляется семантическим токеном в едином CSS-файле. Тёмный hero тоже использует семантические роли, не `text-white` с произвольной прозрачностью.

Единственное sRGB-дублирование для браузерного `meta[name=theme-color]` находится в `src/lib/site.ts`: HTML meta не умеет разрешать CSS-переменные. Браузерный регрессионный тест сравнивает его с фактическим primary, а также проверяет цвет CTA, общую границу полей и стандартные радиусы кнопки/Card/Dialog.
