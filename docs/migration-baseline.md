# Эталон перед миграцией

Исходник: `089d964`; локальный SEO-фикс: `b4a339f`.
React dev: http://localhost:8443/.

Перед началом переноса снято 15 скриншотов (390, 768, 1440 px):

- `/` (полная страница);
- `/#diagnostics`;
- `/#coordination`;
- `/#simulator`;
- `/?food=1`.

Локальные артефакты: `/tmp/governance-baseline/`, результаты DOM/браузерных ошибок: `manifest.json` в этой папке. Это временные локальные файлы, не часть репозитория. При необходимости эталон можно воспроизвести из сохранённого React-worktree.

Для этих входов не обнаружены pageerror и горизонтальное переполнение на проверенных ширинах. Это не подтверждает корректность всех действий внутри демо, доставки заявок или accessibility.

Первый этап: SvelteKit-основа + шапка + hero + языки + мобильное меню, отдельно от React-эталона. Остальные секции и демо переносятся после визуального согласования образца.

Контрольные особенности:

- общий бренд: #2242D6; контейнер до 1170 px;
- IBM Plex Sans и Mono, Inter для демо;
- hero: `team-main.png`, фон `graphs.mp4`, затемнение, fade в белый;
- старые hash/query входы следует поддержать после реализации соответствующих страниц;
- форма: FormSubmit, реальная доставка не проверена; не отправлять тестовые заявки;
- RU/KZ/EN пока переключают только метку;
- MobileApp не подключён к текущему приложению;
- старый service worker нужно учесть перед публикацией новой версии.
