Технический перенос завершён. Визуальная приёмка, согласование содержания и публикация остаются открытыми. Отправка рабочих веток в Git не разрешает деплой.

## Реализовано

- Главная по задачам: проблема → подход → пример → роли → доверие → контакт.
- Диагностика → моделирование → координация; все 18 исходных сценариев и шесть презентаций сохранены в канонических группах без дублирующих продуктов. Advisor — только в координации.
- FoodFlow: три верхние вкладки, все шесть исходных секций и действия. Сохранены партии, фильтры, FEFO, движение, параметры периода, исходный расчёт порчи, граф/память, approvals, происхождение, журнал и отчёт.
- RU/KK/EN, прямые локализованные маршруты, старые hash/query-входы, Back/Forward. Публичные страницы предрендерены с соответствующими locale/SEO; контент доступен без JS.
- Все 43 пути исходных инфографик сопоставлены HTML/SVG/chart-компонентам, включая архивы, Dialog и постеры. Растры остаются эталонами; видео и фотографии — медиа.
- FormSubmit: явное согласие, валидация, защита от дублей, pending/acknowledged/error/timeout, 15-секундный abort и cleanup. API acknowledgement не подтверждает доставку письма. Агентские проверки используют mock-сеть.
- `static/sw.js` — tombstone старого Governance worker: удаляет только его кеши/registration; нет fetch handler, принудительного reload или новой регистрации.

Демо используют исходные синтетические данные. Нет live AI, подключённой БД, камеры, QR-сканера или новой расчётной системы. Презентационные показатели не являются подтверждёнными результатами внедрения.
