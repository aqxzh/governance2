# Текущий результат локальной миграции

## Реализовано

- Отдельный worktree `../website-svelte`, ветка `migration/sveltekit`; React остаётся в `../website`.
- Svelte 5 + SvelteKit 2 + TypeScript strict + adapter-static/SSG; pnpm и lockfile.
- Официальные компоненты shadcn-svelte: Button, Sheet, Dialog, Card, DropdownMenu, Tabs, Table, Badge; Input, Label, Textarea, Separator установлены для следующего этапа.
- Тема на Tailwind v4 и semantic tokens shadcn, контейнер 1170px, IBM Plex Sans/Mono с локальным хостингом. По визуальной обратной связи стандартизирована на готовых палитрах Zinc + Blue и стиле Vega; локальные радиусы/тени/обводки примитивов убраны. Правила — в `design-system.md`.
- Перенесены бренд/шапка/hero и следующий блок главной — контуры. Временный ContourPreview заменён на три вкладки и полный реестр: 6 решений симулятора, 7 диагностики, 5 координации. Desktop использует Table, mobile — Card без горизонтальной прокрутки таблицы.
- Все 18 решений открывают локальные иллюстрации в Dialog; диагностика и координация имеют видео с обработкой ошибки. Нумерованные ссылки шапки выбирают соответствующую вкладку реестра. Полные страницы и интерактивные демо пока доступны по явным ссылкам на локальный React-эталон.
- Тексты реестра перенесены из исходного tabData/simulatorSlides; показатели вроде «50 000+ профилей» не придуманы, но требуют редакторской проверки вместе с остальным исходным контентом.
- Следующий по порядку блок — TeamSection — перенесён: четыре роли/этапа с методами и артефактами, руководитель внедрения и три принципа. Использованы штатные Card, Badge и Separator на общих токенах Zinc+Blue. Имена, фотографии и биографии не придуманы; исходник описывает профессиональные роли, а не персоналии. Контент виден сразу и без JavaScript; декоративная бесконечная анимация исходника не скопирована.
- RU/KK/EN через Paraglide: тексты, подписи, alt, модалки, SEO. Язык задаётся URL; переключение сохраняет путь/фрагмент и загружает предрендеренный HTML целевой локали.
- Мобильное меню на Sheet, модалки на Dialog, локализованное закрытие, Escape/возврат фокуса.
- Переключатель языка — глобус в правом углу шапки на DropdownMenu. Меню показывает полные имена RU/KZ/EN и отметку текущего языка; поддерживает клавиатуру. Без JavaScript доступны обычные ссылки в noscript. Дублирующий переключатель из мобильного Sheet удалён.
- Контактный Dialog не отправляет данные. PDF отсутствует, это явно указано.
- По принятой визуальной обратной связи hero-видео автоматически запускается без звука после гидратации; кнопка позволяет остановить и снова включить его. При prefers-reduced-motion остаётся статичный постер и ручной запуск.
- Title/description, canonical, hreflang, Open Graph, robots.txt, sitemap для реализованных главных страниц.

## Технические уточнения, найденные проверками

- Svelte CLI создал Kit 3, но установленный Bits UI/runed требует Kit 2. Выбрана совместимая связка Kit 2.70.3 + adapter-static 3.0.10; нет незакрытого peer-conflict.
- URL-шаблоны Paraglide должны учитывать порт (`::port?`) и необязательный путь (`:path(.*)?`). Добавлены регрессионные тесты для production-origin, localhost и 127.0.0.1.
- Параметры query/hash нельзя читать при предрендеринге. Суффикс переключателя учитывается только в браузере.
- `paths.relative: false` предотвращает утечку временного origin `sveltekit-prerender` в ссылки. Корректность статического HTML проверяется отдельно, включая работу без JS.
- Для доступности добавлен prop `closeLabel` в установленные Sheet.Content/Dialog.Content. Поведение фокуса и закрытия остаётся штатным Bits UI.
- Правило ESLint `svelte/no-navigation-without-resolve` отключено внутри универсального shadcn Button (href разрешает вызывающий код) и для ссылок LanguageSwitcher: Paraglide разрешает виртуальные locale-пути, не являющиеся route ID SvelteKit. Небезопасные приведения типов для resolve() не используются.
- Селекторы официальных Tabs адаптированы к установленному Bits UI 2: data-state и data-orientation вместо data-active/data-horizontal, без изменения штатного дизайна или поведения. Неактивные панели остаются в статическом HTML; без JS показываются все три реестра.
- Вкладки обновляют fragment через Kit goto с replaceState/noScroll/keepFocus: shallow replaceState не обновляет page.url и оставлял устаревший якорь в переключателе языка. Прямой hash, клавиатура, обновление и язык проверены браузером. Вызов goto имеет узкое исключение ESLint для Paraglide поверх resolve('/').
- Телефонная ссылка нормализована из отображаемого номера исходника `+7 (776) 173-82-91`. Исходный React href содержал несовпадающую последовательность цифр; отображаемый номер не изменён.

## Медиа и визуальная проверка

Исходные файлы: `../website/imports/team-main.png`, `../website/public/videos/graphs.mp4`. PNG сохранён в исходной Git-истории. Оптимизированы только производные, видео скопировано без изменения.

Команды обработки (ImageMagick + FFmpeg, нужны только для повторной генерации):

```sh
magick ../website/imports/team-main.png -resize 1032x -quality 85 static/images/team-main.webp
magick ../website/imports/team-main.png -resize 516x -quality 85 static/images/team-main-small.webp
ffmpeg -ss 1 -i ../website/public/videos/graphs.mp4 -frames:v 1 -vf 'scale=1170:-1' -update 1 static/images/graphs-poster.webp
```

Hero PNG: 696 KiB → WebP 33/89 KiB; фоновый poster ~8 KiB. Изображения имеют width/height, srcset/sizes; видео загружается при автозапуске после гидратации, а при reduced-motion — только после ручного включения.

Эталон: 15 скриншотов пяти основных входов на 390/768/1440px в `/tmp/governance-baseline/`. Новый образец: 9 снимков трёх языков на тех же ширинах в `.artifacts/preview/`, плюс viewport-снимки hero. Артефакты локальные и не коммитятся.

GLM-5.3-flash сравнил desktop/mobile с исходником. По замечаниям возвращены точки в языковом переключателе, приглушён/кадрирован фон, добавлена подложка кнопке видео и уменьшен нижний мобильный отступ. Это вспомогательная оценка; пользовательская визуальная приёмка ещё требуется.

Медиа контуров: 21 WebP (3 баннера + 18 иллюстраций), суммарно ~3 MiB. MOV/HEVC диагностики и координации перекодированы в H.264/AAC MP4 с faststart, сохранён звук: ~2.7/4.4 MiB вместо ~26/37 MiB. Эти видео загружаются только при открытии Dialog и удаляются при закрытии. Подписи в изображениях/видео остаются русскими; в KK/EN это явно указано. Субтитры исходных роликов не предоставлены, это остаётся задачей доступности до публикации.

Происхождение, размеры и кодеки записаны в `contour-media.json`; воспроизводимая обработка — `scripts/prepare-contour-media.mjs`. Новые viewport-снимки всех вкладок/языков — `.artifacts/preview/contours-*.png`; React-эталон этого блока — `/tmp/governance-contour-reference/`. Замечания о высоте вкладок и переносе казахского слова исправлены; финальные desktop/mobile скриншоты проверены напрямую текущей vision-моделью по новой инструкции пользователя, без обрезок/пересечений в исправленных вкладках.

Команда: новые скриншоты `team-{ru,kk,en}-{390,768,1440}.png` просмотрены напрямую текущей моделью, структура сверена с React. Проверены длинные казахские тексты и одинаковое оформление карточек. Захват больших секций использует page clip, чтобы скрытая за верхней границей viewport ссылка skip-content не появлялась как артефакт element screenshot.
