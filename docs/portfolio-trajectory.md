# Портфельные кривые: происхождение и ограничения

`src/lib/components/infographics/PortfolioTrajectory.svelte` используется в `MarketInfographic.svelte`. Кривые повторяют исходную SVG-геометрию, **не восстановленный годовой набор данных**.

## Источник

React-архив: `archive/react-reference` (`37f31c2`), каталог `src/simulator/slides/module-3/`.

- `index.tsx`, `Component`, variant `2`, строки 12–116: вложенные viewBox, процентное размещение и ширина штрихов. Сетка: y=16/52/88/124/158 в поле 1040×178; горизонтальная область примерно x=112–960.
- `svg-gjub12lwvb.ts`: значения `d` скопированы дословно, без числового семплирования.

## Геометрия, а не данные

Bézier-координаты — презентационная геометрия, не измеренные прогнозы спроса. Не интерполировать годовые значения, единицы или числа для salads/frozen. Вложенные viewBox и процентное размещение сохраняют относительную форму, включая округления исходного React-экспорта.

Декоративные заливки первых трёх путей, направляющая/точки tooltip и overlay опущены. Цвет — семантический `var(--primary)`, кривые различаются штрихованием; это не pixel-identical стиль. Responsive SVG использует поле 1040×178 и высоту графика 144 px. Шкала и локализованная легенда — HTML вне SVG, без растровой вставки или `foreignObject`.

## Контракт компонента

Обязательные строковые props: `title`, `caption`. Родитель передаёт Paraglide-сообщения `inf_market_portfolio_forecast_title` / `inf_market_portfolio_forecast_caption`; подпись должна явно отличать исходные иллюстративные траектории от годовых числовых данных. Категории используют `inf_market_portfolio_cat_*`. SVG имеет доступные title/description; видимая подпись остаётся доступна assistive technology.

Отдельный график и таблица **трёх чисел 2027 года** в `MarketInfographic` сохраняются. Не заменять их таблицей из SVG-координат и не выдавать иллюстрацию за работающий симулятор.
